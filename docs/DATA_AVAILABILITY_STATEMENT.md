# Data Availability Statement

The public release contains the curated v3.4 contact-angle dataset, fixed split manifest, source reference map, locked LOO-SFE corrected result tables, paired statistical tests, figure-generation inputs, and high-resolution figure source files supporting the associated manuscript.

The package does not include article PDFs, publisher-owned source figures, private project notes, local machine paths, or internal review comments.

The primary clean external conclusion is based on the 114 LOO-SFE feasible source-disjoint external samples. The original all-liquid apparent-SFE source-disjoint result is retained only as leakage-risk sensitivity, and the 34 LOO-SFE-infeasible or high-risk source-disjoint samples are retained only as diagnostic appendix material.

Repository DOI and final article DOI can be added to this statement after public deposition.
